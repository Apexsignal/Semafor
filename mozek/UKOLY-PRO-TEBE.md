# Úkoly pro tebe

Věci, co potřebuju od tebe, abych mohl pokračovat — nic z tohohle nejde
udělat za tebe (potřebuje to tvoji identitu, přihlášení nebo rozhodnutí).
Průběžně aktualizuju, jak se co vyřeší.

## Potřeba brzy

- [ ] **Resend API klíč** — zaregistruj se na [resend.com](https://resend.com),
      Settings → API Keys → Create API Key, pošli mi hodnotu (`re_...`).
      Bez toho zůstává přihlašování na limitovaném testovacím e-mailu Supabase.
- [ ] **Jméno/firma, adresa, kontaktní e-mail** — pro Obchodní podmínky a
      Ochranu osobních údajů (teď tam jsou placeholdery `[doplnit]`).

## Až budeš mít čas/prostředky

- [ ] **Anthropic kredit** — console.anthropic.com → Settings → Plans & Billing.
      Klíč je v pořádku nastavený, jen bez kreditu cron pořád padá na Gemini.
- [ ] **Stripe účet** — potřeba bankovní účet napojený na IČO. Založení samo
      je zdarma (platí se jen provize z transakcí).
- [ ] **Signi účet** — elektronický podpis smluv o dílo pro zakázky.
- [ ] **Fakturoid nebo iDoklad účet** — vystavování faktur.
- [ ] **Telegram bot** (volitelné) — `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID`,
      pokud chceš dostávat upozornění na silné nápady a výpadky poskytovatele.
